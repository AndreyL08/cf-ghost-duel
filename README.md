# CF Ghost Duel

Дуэль 1v1 на задачах Codeforces против «призрака» — записи реального участника того контеста, откуда взята задача. Соперник воспроизводит попытки и время решения по таблице результатов; если рейтинговых данных нет, играет синтетический соперник.

Один самодостаточный `index.html`, без сборки. Запросы к API Codeforces идут напрямую из браузера через `fetch`.

## Запуск

- Локально: открыть `index.html` в браузере.
- GitHub Pages: Settings → Pages → Deploy from branch → `main`, папка `/ (root)`.

Подробности об устройстве и решениях — в [docs/context.md](docs/context.md).
